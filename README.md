# Ecological Predictive Cruise Control for EVs

## Project Overview
This project implements an energy-efficient Adaptive Cruise Control (ACC) 
system for electric vehicles using LSTM neural networks for traffic prediction 
and Model Predictive Control (MPC) for optimization.
